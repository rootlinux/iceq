Safe installation

Install IceQ only from the verified IceQ origin. Messaging and end-to-end encryption require JavaScript and do not work without it. Review requested browser permissions before accepting.

Güvenli kurulum

IceQ'yu yalnızca doğrulanmış IceQ adresinden kurun. Mesajlaşma ve uçtan uca şifreleme JavaScript gerektirir ve JavaScript olmadan çalışmaz. Kabul etmeden önce tarayıcı izinlerini inceleyin.
